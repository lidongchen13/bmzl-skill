# 交付前自检清单

逐条打勾；任一条不通过就不要交付。

## A. 结构（缺一即退稿）

- [ ] 0. 原文信息 六行齐全：作者、题目、期刊、时间、DOI
- [ ] 标题为 `【笔墨之林】<缩写>: <主标题>——<副标题>`，英文冒号 + 空格，中文破折号
- [ ] 【推荐理由】存在，**≤120 字符**
- [ ] 1 研究背景 = **3 段**（经济问题 / 背景事实 / 本文做了什么）
- [ ] 2 研究内容 = 2.1 研究数据 + 2.2 研究方法 + 2.3 研究结果
- [ ] 2.2 含 **两个** 回归方程，且各自有「式中」说明（下标 i/c/m/t、Y、R、X、Φ、ε）
- [ ] 2.3 = 每表一段（总括→结果与含义→加粗收束）+ 末段（适应行为 + 投影方法 1–2 句 + 结果）
- [ ] 3 研究结论与贡献 = **2 段**（方法+结果+机制 / 三点贡献）
- [ ] 4 本期作者 有照片占位与一句简介
- [ ] 若基于工作论文版本，文末已注明

## B. 内容

- [ ] 每张表的结果都点名了对应列（`(第1列)`、`(第3、4列)`、`(第1至6列)`）
- [ ] 每个系数都能在表中找到，且符号方向与正文一致
- [ ] 不显著的结果也写了，并给了经济解释
- [ ] 机制链条完整：处理 → 中间变量 → 结果，且与论文一致
- [ ] 结论段不重复 2.3 的数字
- [ ] 没有编造数字、月份、作者单位
- [ ] 没有超出论文证据的断言（「证明」→「表明」，「必然」→「可能」）

## C. 语言

- [ ] 全文第三人称，无「我们」
- [ ] 无「同时/与此同时」「但是」作段首、无「颠覆了」「较多」「几天」
- [ ] 句子普遍 ≤2 行，无「一逗到底」
- [ ] 冒号前不冗长
- [ ] 中英文标点分工正确；数字前后无空格
- [ ] 括号全为英文半角，且邻接字符的空格规则正确
- [ ] 无斜体（公式截图除外）
- [ ] 无错别字：「反映/反应」「的/地/得」「A、B、C 和 D」

## D. 格式

- [ ] Word 字数 1,000–2,500（按约定口径取 `build_docx.py` 的「全文」或「正文」数字）
- [ ] 中文仿宋小四、英文 Times New Roman、两端对齐、无首行缩进
- [ ] 段间空一行；节首段前、末段后各空一行
- [ ] 图表 ≤3 张，且**为论文原表截图**，不含英文表题与 Notes
- [ ] 表题在图表上方、居中、`表N: ……` 英文冒号
- [ ] 表题前空一行，图表后空一行
- [ ] 表格 ≤6 列（超过时改选更窄的表或裁列）
- [ ] 公式为白底截图，上下各空一行，下标清晰
- [ ] 封面图有来源注（`注：……`）；正文图表不加来源注（团队约定）
- [ ] 未使用含中国地图的图片

## E. 交付

- [ ] 文件名 `<短标题>_笔墨之林.docx`
- [ ] 用 Word 打开确认：无空页、无跨页断表、标题不与正文分离
- [ ] 向用户说明哪些占位符需要替换（作者照片、姓名、单位、研究方向）
- [ ] 报告字数与图表数量
